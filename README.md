# G.S.L Eventos infantiles

Página de enlaces para redes sociales y contacto.

## Archivos
- `index.html`: contenido y enlaces.
- `styles.css`: diseño adaptable a celulares y computadoras.
- `script.js`: año automático del pie de página.

## Publicar gratis con GitHub Pages
1. Crea un repositorio público en GitHub, por ejemplo `gsl-eventos`.
2. Sube estos tres archivos a la raíz del repositorio.
3. En GitHub abre **Settings → Pages**.
4. En **Build and deployment**, elige **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`; guarda.
6. Espera a que GitHub publique el sitio. La dirección normalmente será:
   `https://TU-USUARIO.github.io/gsl-eventos/`

## Código QR
Genera el QR después de publicar, usando la URL definitiva de GitHub Pages. Así el QR seguirá funcionando mientras mantengas esa dirección. Prueba el QR con otro teléfono antes de imprimirlo.
