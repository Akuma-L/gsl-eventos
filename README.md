# G.S.L Eventos infantiles

Sitio web desarrollado para G.S.L Eventos infantiles, una pequeña empresa dedicada al sector de eventos infantiles.

## Sobre el proyecto

Este proyecto nació con la idea de crear un espacio digital donde los clientes puedan encontrar fácilmente los principales medios de contacto de la empresa.

La página reúne sus perfiles de Instagram y TikTok, así como su correo electrónico, mediante una interfaz sencilla, colorida y adaptable a distintos dispositivos.

El diseño incorpora elementos gráficos minimalistas y una identidad visual alegre, buscando transmitir la esencia de los eventos infantiles.

## Características

- Diseño adaptable a dispositivos móviles y computadoras.
- Interfaz colorida y amigable.
- Ilustraciones decorativas minimalistas en SVG.
- Acceso directo a Instagram y TikTok.
- Contacto mediante correo electrónico.
- Año actualizado automáticamente.

## Tecnologías utilizadas

- **HTML5:** estructura de la página.
- **CSS3:** diseño, colores y animaciones.
- **JavaScript:** funcionalidades dinámicas.
- **SVG:** iconos e ilustraciones.
- **GitHub Pages:** alojamiento y publicación.
